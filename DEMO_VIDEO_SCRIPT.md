# Demo Video Script - Personal Wallet App
**Version**: 3.0.0
**Duration**: ~5-7 minutes
**Features**: Dark Mode, Edit Wallet, Transaction Date Picker, Export to CSV, Edit Transaction

---

## 🎬 Video Structure

**Total Duration**: 5-7 minutes
- Intro: 30 seconds
- Feature 1 (Dark Mode): 45 seconds
- Feature 2 (Edit Wallet): 60 seconds
- Feature 3 (Date Picker): 60 seconds
- Feature 4 (Export CSV): 90 seconds

## 📱 Pre-Demo Setup

### App State Before Recording
1. **Sign in** with test account
2. **Create wallets**:
   - "Main Wallet" - $1,500 balance
   - "Savings Account" - $5,000 balance
   - "Cash" - $200 balance
3. **Add transactions** (10-15 total):
   - Various dates (past week)
   - Mix of INCOME, EXPENSE, TRANSFER
   - Different categories: Food, Transport, Entertainment, Salary
   - Include one with special characters: "Lunch, at Joe's Cafe"
4. **Phone settings**:
   - Set to Light theme (will demo dark mode switch)
   - Portrait orientation
   - Screen recording enabled
5. **Close background apps** for clean demo

## 📝 Production Notes

### Recording Settings
- **Resolution**: 1080p minimum
- **Frame Rate**: 60 FPS for smooth UI
- **Audio**: Clear voiceover, no background music during demo (optional light music during intro/outro)
- **Screen Recording**: Use Android Studio's screen recorder or scrcpy for best quality

### Editing Tips
1. **Annotations**: Use circles/arrows to highlight buttons being tapped
2. **Speed**: Slightly speed up (1.2x) repetitive actions like scrolling
3. **Transitions**: Quick cuts between features (no long fades)
4. **Text Overlays**: Keep on-screen text visible for 3-5 seconds minimum
5. **Zoom**: Zoom in on small UI elements like icons (Edit, Export buttons)

### Voiceover Tips
- **Pacing**: Speak clearly at moderate pace (not too fast)
- **Enthusiasm**: Sound excited about features without being overly salesy
- **Pauses**: Brief pause after "Let's [action]" before performing action
- **Tone**: Professional but friendly, instructional

### Alternative Versions
Consider creating:
1. **Quick Version** (2 minutes): Show only the highlights of each feature
2. **Silent Version**: Text overlays only, for social media
3. **Feature Spotlight**: Individual 1-minute videos for each feature
